# Engineering Research

Claude Code plugin marketplace for **Engineering Research** (Public Alpha): evidence-based
engineering product research and selection, with an independent critic. It supports engineering
judgment; it does not replace it.

```bash
claude plugin marketplace add alsterling/engineering-research
```

```bash
claude plugin install engineering-research@engineering-research-marketplace
```

What it does, the RUN and CRITIC skills, and usage examples:
[engineering-research/README.md](engineering-research/README.md).
